# How well do you know Catalyst? (quiz)

A 10-question quiz about Catalyst. You get a score out of 10, a rank, and a score card you can download or share on X.

made by @iamlogtun · not official

## Deploy

vercel.com/new → Import this repo → Deploy

- Framework Preset: **Other**
- Build Command: none (leave empty)
- Output Directory: leave as default (the site is at the repo root)

It's a plain static site: no build step, no environment variables.

## After the first deploy

The share caption and the link on the card use whatever address the site is opened on, so they follow your Vercel URL automatically.

For the link preview on X/WhatsApp, some apps need a full image URL. Once you know your Vercel address, you can change `og.jpg?v=2` in `index.html` (the `og:image` and `twitter:image` tags) to the full URL, e.g. `https://YOUR-PROJECT.vercel.app/og.jpg`.
